Projeto: Fiscaliza Aí

1. TEMA:
Desenvolvimento de uma plataforma web para registro e comunicação de denúncias relacionadas a problemas urbanos, promovendo a conscientização e a participação cidadã na identificação de situações que afetam a infraestrutura e a qualidade de vida da população.

2. DESCRIÇÃO:
O Fiscaliza Aí é um sistema de denúncias urbanas desenvolvido como projeto acadêmico para a disciplina de Desenvolvimento Front-End, envolvendo os cursos de Engenharia de Software e Ciências da Computação.
A plataforma permite que os cidadãos registrem problemas urbanos, como buracos nas ruas, falta de iluminação pública, acúmulo de lixo, calçadas danificadas e problemas de saneamento básico.
O sistema foi desenvolvido para possibilitar o preenchimento e o envio de denúncias diretamente pelo navegador, sem realizar o armazenamento das informações em um servidor.

3. OBJETIVO GERAL:
Desenvolver uma plataforma web intuitiva e acessível que permita aos cidadãos registrar e comunicar problemas urbanos, incentivando a participação da população na identificação de necessidades e melhorias na infraestrutura das cidades.

4. OBJETIVOS ESPECÍFICOS:
- Desenvolver uma interface web intuitiva, organizada e de fácil utilização.
- Permitir o registro de diferentes tipos de problemas urbanos.
- Disponibilizar um formulário para preenchimento e envio de denúncias.
- Facilitar a comunicação de problemas relacionados à infraestrutura urbana.
- Promover a conscientização e o engajamento da população na melhoria dos espaços públicos.
- Aplicar os conhecimentos de desenvolvimento Front-End adquiridos durante a formação acadêmica.
