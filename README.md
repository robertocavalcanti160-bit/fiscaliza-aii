# Fiscaliza Aí

Sistema de Denúncias Urbanas. Projeto acadêmico da disciplina de Desenvolvimento Front-End, dos cursos de Engenharia de Software e Ciências da Computação.

A plataforma permite registrar problemas urbanos, como buracos nas ruas, falta de iluminação pública, acúmulo de lixo, calçadas danificadas e problemas de saneamento. O envio é tratado no navegador, sem armazenamento das denúncias em servidor.



## Páginas

| Arquivo | Conteúdo |
| --- | --- |
| `index.html` | Página inicial |
| `problemas.html` | Categorias de problemas |
| `denunciar.html` | Formulário de denúncia |
| `sobre.html` | Sobre o projeto |
| `contato.html` | Dados e repositório |
| `obrigado.html` | Confirmação após o envio |
